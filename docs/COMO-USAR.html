1. Baixar e abrir

  1. Abra a página de Releases do FrameCut.
  2. Na seção Assets, baixe FrameCut-portatil.zip. Escolha esse arquivo para ter o aplicativo e este tutorial juntos.
  3. Na pasta Downloads do Windows, clique com o botão direito no ZIP e escolha Extrair tudo…, depois Extrair.
  4. Abra a pasta extraída e dê dois cliques em FrameCut.html.
  5. Se necessário, use Abrir com → Google Chrome ou Microsoft Edge.

Também pode baixar somente FrameCut.html na release. Esse arquivo já contém todo o aplicativo. Os arquivos “Source code” são os fontes do projeto; o ZIP portátil e o HTML são as opções prontas para usar.

Não precisa instalar Python, Node.js ou Photoshop nem iniciar um servidor. Depois de baixar, pode usar sem internet. As imagens ficam no seu computador.

2. Preparar uma imagem ou um lote

  1. Deixe Quadros por imagem em Automático.
  2. Escolha a largura e a altura da saída; o padrão é 608 × 1600 pixels.
  3. Se quiser manter os textos, desmarque Esvaziar balões automaticamente. A opção vem ligada.
  4. Clique em Escolher imagens e selecione uma ou várias. No Windows, use Ctrl + clique ou Ctrl + A na pasta. Também pode arrastar os arquivos para a área de prévia.
  5. Aguarde o processamento. Clique nos nomes da fila para conferir cada resultado.
  6. Use Baixar este PNG para uma imagem ou Baixar lote em ZIP para todas as imagens prontas.
  7. Abra a pasta Downloads. Extraia o ZIP de resultados para acessar os PNGs.

Quadros lado a lado são extraídos e empilhados de cima para baixo, da esquerda para a direita. Os quadros mantêm proporções relativas à página; os estreitos ficam centralizados.

Confira antes de publicar. A detecção automática pode precisar de correções. Baixe os resultados antes de fechar a aba ou substituir o lote; não há salvamento permanente de projeto.

3. Ajustar as medidas e os espaços

CampoComo usar
Quadros por imagemAutomático permite páginas com quantidades diferentes no mesmo lote. Uma quantidade específica ajuda na revisão.
Largura de saídaDefine a largura do PNG final.
Ajustar espaços para uma altura finalCalcula os intervalos para atingir a altura escolhida.
Espaço fixo entre quadrosDesmarque o ajuste por altura para definir um intervalo igual entre os quadros, em pixels.

Depois de alterar as medidas, clique em Reprocessar lote. Baixar o ZIP também aplica o padrão alterado. Se a altura for pequena demais para o conteúdo, aumente-a ou diminua a largura.

4. Corrigir um recorte

  1. Selecione a imagem na fila.
  2. Clique em Conferir cortes e abra Ajustes manuais e limpeza dos balões.
  3. Escolha Ajustar divisões.

Quando houver bolinhas verdes

  • Arraste uma bolinha existente para movê-la sem criar outro ponto. Os pontos internos se movem na horizontal e na vertical, respeitando os vizinhos.
  • Shift + clique em um trecho livre da linha acrescenta um ponto. A ferramenta Criar ou mover ponto faz isso sem teclado.
  • Arraste um trecho livre para mover a linha. Clique direito perto dela para removê-la.

Quando os recortes forem retangulares

  • Arraste a borda de um quadro para ajustar o recorte.
  • Use Selecionar quadro para desenhar um novo recorte.
  • Clique direito dentro de um quadro para removê-lo.

Desfazer ou Ctrl + Z volta uma etapa. Confira o resultado e reprocese o lote antes de baixar. O histórico de desfazer reinicia ao trocar de imagem; as edições continuam na fila durante a sessão.

5. Esvaziar e retocar os balões

A opção Esvaziar balões automaticamente aplica a limpeza à prévia e à exportação. Nos balões opacos, procura a fala completa; nos transparentes, tenta substituir somente os traços das letras e sua suavização.

O preenchimento é aproximado: detalhes que estavam escondidos pelas letras podem ficar suavizados. Letras coloridas, textos muito curtos e fundos complexos podem exigir retoques.

  1. Para comparar com o original, use Conferir cortes ou desmarque a limpeza.
  2. Se um balão claro não foi limpo, abra os ajustes manuais e escolha Limpar um balão com um clique. Clique no fundo claro, próximo das letras.
  3. Para retoques, use Retângulo, Elipse ou Pincel. Use o Conta-gotas em uma parte limpa para copiar a cor do fundo.
  4. Confira em Resultado automático e baixe novamente.

Seleções e pincel preenchem com cor lisa. Use Desfazer se precisar ajustar a aplicação.

6. Entender os avisos

AvisoO que fazer
RevisarConfira os cortes ou informe a quantidade de quadros. Essa imagem fica fora do ZIP até ser corrigida e reprocessada.
Revisar textoUma fala foi preservada por segurança da máscara. Confira e retoque a limpeza.
0 balõesConfira se ainda há texto. Nenhum balão identificado não significa que a página esteja limpa.
Altura final pequenaAumente a altura ou diminua a largura.
Arquivo abriu como códigoUse botão direito em FrameCut.html → Abrir com → Chrome ou Edge.

O ZIP pode incluir REVISAR.txt, com imagens que ficaram de fora, e CONFERIR-LIMPEZA.txt, com avisos de limpeza.

7. Limites e atualização

  • Entrada: PNG, JPG/JPEG e WebP, até 24 megapixels e 16.000 pixels por lado.
  • Saída: PNG, até 60 megapixels e 32.000 pixels de altura.
  • Até 250 imagens e 300 MB de PNGs por lote. Divida trabalhos maiores.
  • Até 12 quadros detectados automaticamente. Páginas sem bordas, diagonais ou sobrepostas podem exigir recorte manual.
  • Para parar o processamento, use Parar após esta imagem.

Para atualizar, baixe o ZIP mais recente em Releases, extraia em outra pasta e abra o novo FrameCut.html. Salve o trabalho atual antes de fechar a versão antiga.
